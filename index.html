怎么用

    

      
核心操作：左侧点一个 Godot 控件 → 在中间画板按住鼠标拖出矩形 → 松手完成。矩形左上角的紫色小标签是 Godot 节点名，只用于导出和 MCP 建场景，不会作为实际 UI 文本显示。

      
右侧可以改节点名、实际显示文字、位置尺寸、父节点、锚点、预览颜色，以及专门写给 Codex/MCP 的逻辑备注。顶部标签页就是不同 UI 场景，例如“主菜单”“背包”“设置”。每个标签页独立保存一套节点。

      
改进操作：支持 8 点缩放、空格/中键拖动画布、Ctrl/⌘+滚轮缩放、连续绘制、场景右键复制/重命名、自动父子层级、Godot 结构验证，以及 Markdown / .tscn 两种导出。

      
V / Esc
回到选择工具

      
D
进入当前控件的斜拉绘制模式

      
Space + 拖拽
平移画布

      
Delete
删除选中节点

      
Ctrl/⌘ + D
复制选中节点

      
⌘Z / Ctrl+Z
撤销上一步设计操作

      
⇧⌘Z / Ctrl+Shift+Z
重做；Windows 也支持 Ctrl+Y

      
方向键
移动 1px；按 Shift 时移动 8px

      
Ctrl/⌘ + S
直接导出 Markdown

      
导出的 .md 里同时包含人类可读的 UI 规格表和机器可读 JSON。你可以直接把它交给 Codex，让 Codex 通过 Godot MCP 创建 Control 场景、节点、Rect、父子关系和文本。
